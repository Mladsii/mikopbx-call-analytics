# AI-анализ звонков MikoPBX

Основной поток получает записи звонков из MikoPBX, выполняет транскрибацию, классифицирует и суммирует разговоры, формирует документы и передаёт результаты в CRM. Экспорт обезличен; реальные адреса, ключи и идентификаторы нужно задать в n8n.

## Импорт и настройка

`workflow.json` содержит обезличенную схему узлов и связей; параметры узлов удалены, поэтому это не готовый к запуску экспорт. Для запуска восстановите параметры и логику узлов в своей среде n8n, настройте credentials и внутренние ID. Не импортируйте в рабочую среду без проверки каждого узла и маршрута данных.
